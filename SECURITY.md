# Security policy

## Supported versions

Only the latest release receives security fixes. Older development milestones are not supported.

| Version | Supported |
|---|---|
| `1.0.x` (`v1.0.0`) | Yes |
| Pre-1.0 milestones | No |

## Report a vulnerability

Do not report security problems in public issues or pull requests.

Report them privately through [GitHub private vulnerability reporting](https://github.com/andrew-abdelmalak/autonomous-ackermann-vehicle/security/advisories/new).

Include:

- The affected commit, ROS 2 launch configuration, or firmware target
- Steps to reproduce or a minimal reproduction payload
- Expected impact of the issue

## What happens next

We review reports as maintainer availability allows, validate the reproduction locally, and publish a fix and advisory once resolved.
